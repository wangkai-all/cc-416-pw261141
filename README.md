# 观测单位沿革分析台（虚构件量观测网络）

站点会**拆分、合并、迁址**，同一统计名称在不同期间不一定指向同一观测单位。本项目从空目录构建
一条完整的观测数据加工流水线，演示三个服务如何协作，让「单位边界调整」与「真实业务增长」
在分析页面上被正确区分，并支持双口径并列、拆合关系审阅、异常贡献追溯、中断重算恢复。

> 数据全部为程序生成的虚构数据（物流站点月度件量，2023-01 ~ 2026-10），不包含任何真实信息。
> 本项目是数据加工/分析系统，**不是站点管理系统**。

## 快速开始

需要 Python 3.10+（仅标准库，无第三方运行依赖）：

```bash
python3 run.py              # 首次自动建库、造数、产出两个基线分析版
# 打开 http://127.0.0.1:8000
python3 run.py --reset      # 删库重建
python3 run.py --port 8010  # 换端口
```

## 领域模型与核心口径

### 三个协作服务

| 服务 | 模块 | 职责 |
|---|---|---|
| 来源接收 | `app/ingestion.py` | 批次接收、四类校验（未知代码/退役单位/重复批次/异常值）、隔离区放行与拒绝 |
| 单位沿革映射 | `app/lineage.py` | 上报代码有效期解析、版本化拆/合/迁址边、审阅工作流、沿革连通分量（队列） |
| 队列分析 | `app/analysis.py` | 分析版与运行、检查点恢复、双口径计算、调整/有机增长分解、异常贡献追溯 |

### 两个口径（页面并列展示）

- **当时口径 as-reported（直接重述历史）**：只汇总该期间实际上报、且按有效期映射落在本单位的
  源事件。站点拆分后，新单位在拆分生效前没有当时口径数据——它当时还不存在。
- **最新口径 restated（按当前单位边界重述）**：历史事件沿已批准沿革边的全部下游路径按累乘
  权重，用最大余数法整数分摊到今天的单位。权重严格守恒：任一期间全单位重述量之和等于源事件总量。

### 调整不是增长

沿革边生效期间，承接单位记 inbound 调整量、移交单位记 outbound 调整量。对任意单位、任意期间恒有：

```
环比总变化 = 结构调整净额（拆/合/迁址） + 有机变化（真实业务增减）
```

队列是沿革连通分量，权重在队列内部搬移，因此**队列层面结构调整净额恒为 0，两个口径始终重合**。

### 版本化与修订

- 映射边按 `mapping_version` 整体快照；新增/修订边初始为 `proposed`，**审阅通过前不参与任何计算**。
- 修订映射后创建新的分析版（`analysis_version` 绑定映射版本），旧分析版只读保留，页面可并列对比。
- 基线剧情：映射 v1 **漏接** U06 西关站 → U07 枢纽的合并边；v2 补登该边并审阅重算，
  对比页可见 U07 的历史重述线上移，而两版当时口径完全相同（修订映射不重写历史）。

## 预置剧情（可在页面逐一点验）

1. **拆分**：U01 城北旧站 2024-07 按 55%/45% 拆为 U02/U03。
2. **迁址更名**：U03 城北西片站 2025-03 整体迁址为 U04 滨河新区站（上报代码 S03→S04）。
3. **合并 + 映射错误修订**：U05 东关 + U06 西关 2025-07 合并为 U07；v1 漏接 U06 边，v2 修订。
4. **先拆后合**：U09 南城临时站 → U10 南城中心站 → 并入 U07（多跳路径分摊）。
5. **异常贡献**：2025-09 U07 大客户双节促销批量件（BULK-2025-091），可在「单位分析 → 异常贡献追溯」
   沿沿革路径追到源事件与批次。
6. **隔离区四类拦截**：重复批次、落入退役单位（S03 在 U03 退役后的新数据）、未知代码 S99、
   超阈值异常值。退役/未知代码**禁止直接放行**，必须先处理映射或主数据。
7. **中断恢复**：「重算与审计」页可演练启动→中断→从最后检查点恢复，结果与一次跑完逐行一致。
8. **稳定对照组**：U08 临港综合站全程无沿革变化，两条口径线天然重合。

## 页面结构

| 标签页 | 内容 |
|---|---|
| 总览 | KPI、队列双口径折线（黄色竖带标沿革生效期）、队列汇总 |
| 单位分析 | 单位双口径序列、环比变化发散条形分解（灰=结构调整，蓝=有机变化）、异常贡献追溯 |
| 版本对比 | 两个分析版并列折线、逐期间重述差异表（当时口径差异恒为 0） |
| 沿革审阅 | 拆/合/迁址边审阅（通过/驳回/改权重）、沿革图泳道、上报代码有效期映射、修订出新版本 |
| 来源与隔离 | 隔离区操作、源事件清单（含映射到的规范单位）、演示批次投递 |
| 重算与审计 | 运行状态与检查点进度、中断/恢复、全量审计日志 |

所有图表均有「查看数据表」孪生视图；图表使用内联 SVG 手绘，无外部前端依赖，支持亮/暗双主题。

## 存储

SQLite（`data/observatory.db`，已被 `.gitignore` 忽略）。关键表：

- 映射侧：`canonical_unit`、`mapping_version`、`lineage_edge`、`mapping_entry`、`edge_review`
- 源数据侧：`source_batch`、`source_event`（不可变 + dedup 唯一键）、`event_flag`
- 分析侧：`analysis_version`、`analysis_run`、`analysis_result`、`adjustment`、`cohort_membership`
- 审计：`audit_log`
